# ポジティブ変換定規 (Peaceful Web Translator) - Chrome & Firefox 拡張機能

SNS、動画コメント欄、掲示板などのWebページを閲覧中、攻撃的な言葉や誹謗中傷・煽りスラングを、ブラウザ内でポジティブ＆ユーモアあふれる表現へ自動変換するツールです。

---

## ディレクトリ構造 (ZIPパッケージ解凍時)

本ZIPアーカイブには `manifest.json` が参照するサブフォルダ `icons/` が正しく格納されており、ブラウザ読み込み時の参照エラーを完全に防ぎます。

```text
peaceful-web-translator-extension.zip
├── manifest.json                  # 拡張機能マニフェスト (Chrome: V3 / Firefox: Gecko対応)
├── background.js                 # 拡張機能ライフサイクル管理
├── content.js                    # テキスト走査・リアルタイム自動変換スクリプト
├── popup.html / popup.js         # ポップアップ画面 (ワンクリックON/OFF切り替え)
├── options.html / options.js     # 設定画面 (カスタム変換ルールの追加・編集・削除)
└── icons/                        # アイコンサブフォルダ (実在保証)
    ├── icon16.png
    ├── icon32.png
    ├── icon48.png
    └── icon128.png
```

## インストール手順

### 1. Google Chrome への導入 (開発者モード)
1. ダウンロードした ZIP ファイルを展開（解凍）します。
2. Chrome を開き、アドレスバーに `chrome://extensions/` と入力して開きます。
3. 画面右上の **「デベロッパーモード」** を ON にします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 解凍したフォルダを選択します。
6. 拡張機能バーに「ポジティブ変換定規」が表示されれば準備完了です！

### 2. Mozilla Firefox への導入 (一時アドオン)
1. ダウンロードした Firefox用 ZIP ファイルを展開します。
2. Firefox を開き、アドレスバーに `about:debugging` と入力して開きます。
3. 左メニューの **「この Firefox」** をクリックします。
4. **「一時的なアドオンを読み込む...」** をクリックし、解凍フォルダ内の `manifest.json` を選択します。
*(Firefox用パッケージの `manifest.json` には `browser_specific_settings.gecko.id` がプリセットされています)*

## 使い方・機能

- **ワンクリックON/OFF**: ツールバーのアイコンをクリックし、ポップアップからいつでも変換の有効/無効を切り替えられます。
- **リアルタイム自動変換**: タイムラインのスクロールやYouTubeコメントの動的読み込みにも自動追従して変換します。
- **310語以上の標準辞書**: インターネット上の代表的なトゲのある言葉や煽りスラングを幅広くカバー。
- **カスタム辞書機能**: 設定画面（オプション）から、自分好みの変換単語やフレーズを自由に追加・編集・削除できます。

---

## プライバシーポリシーとセキュリティ

- **完全ローカル動作**: 外部サーバーへの通信は一切行いません。すべてのテキスト処理は端末内のブラウザ上でのみ完結します。
- **データ非収集**: 個人情報、閲覧履歴、Cookie、ページ内入力テキストの収集・保存・外部送信は一切行いません。
- **安全設計**: Webページのレイアウトやリンク機能を壊さず、テキストノードのみを安全に置換します。
